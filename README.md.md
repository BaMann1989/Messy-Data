# Project 3: Messy Data Cleanup

## Problem
The raw data was messy, had duplicates and many things were not formatted correctly so math equations couldn't take place.

## Approach
I started by formatting the headings and then worked my way through cleaning the data, sorting everything properly and formatting quantity and price as numbers, then I created a clean table and validated it.

## What I did
- Names: I formatted each name the same way so the table would be consistent.
- Dates: I converted them to one format.
- Duplicates: I erased all duplicates while being careful not to lose any important information.
- Number: I converted them from text to numbers.
- Sorting: I sorted the table by region, then by customer.
- Then I created a table and validated each relevant piece.

## Outcome
The data is now in an organized table that will allow for calculations

## What I'd do differently
Next time I would start with the conversions and work my way from there.

## Skills demonstrated
I used formatting, formulas, sorting, creating a table, and table validation
